## What it does

`main.py` (Python 3, standard library only) writes a single original funny
line — 95 characters — to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`).

## Run it

```bash
python3 main.py
```

Then read the line:

```bash
cat /output/entry.txt
```
